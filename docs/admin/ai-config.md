# AI 服务商与模型

AI 相关配置（服务商、模型、API Key）**存储在数据库中**，通过界面管理，可**热切换**、无需重启。

配置分两层：

| 层级 | 入口 | 谁可以配置 | 谁可以使用 |
|------|------|-----------|-----------|
| 全局 | 设置 → **全局 AI 模型** | 超级管理员 | 所有用户 |
| 个人 | 设置 → **我的 AI 模型** | 任意登录用户 | 仅本人 |

## 添加服务商

点击「添加服务商」，按三步向导完成：

1. **选择服务商**：DeepSeek、通义千问、智谱 GLM、Kimi、OpenAI、Google Gemini，或「其他 / 自定义」（任何兼容 OpenAI 接口的服务、私有部署或中转）。预设会自动填好接口类型和地址。
2. **填写 API Key 并测试连接**：系统会用 Key 请求服务商的模型列表。连接失败会给出原因（Key 无效、地址错误、超时等）；部分服务商不提供模型列表，可跳过后手动填写。
3. **勾选要使用的模型**：「识图」「向量」标记按模型名自动推断，可点击修改；也可手动添加模型名。

添加完成后，如果某些功能还没有配置模型，系统会**预选**新服务商中合适的模型，但不会自动保存，需要你在「当前在用」中确认。

服务商卡片上可以：启用 / 停用、编辑连接信息（API Key 留空表示不修改）、测试连接、添加模型、编辑模型的名称和能力标记、删除。正在被使用的模型会显示「文本模型」「识图模型」等标记。

## 模型能力

| 标记 | 含义 | 可用于 |
|------|------|-------|
| （无标记） | 普通文本模型 | 文本模型 |
| 识图 | 可处理图片输入 | 文本模型、识图模型 |
| 向量 | Embedding 模型，只做向量化，不能对话 | 向量模型 |

下拉框只会列出能力匹配、且服务商已启用的模型。

## 当前在用（全局）

| 用途 | 系统参数键 | 影响功能 |
|------|-----------|---------|
| 文本模型 | `AI_TEXT_MODEL_ID` | [AI 对话](/features/chat)、文本类导入抽取、知识点匹配 |
| 识图模型 | `AI_VISION_MODEL_ID` | 图片识别导入 |
| 向量模型 | `AI_EMBEDDING_MODEL_ID` | [知识点 RAG](/features/knowledge-points)、相似题检索 |

每一项都会显示状态：**可用**、**未配置**（该功能暂不可用），或**不可用**（服务商已停用、模型已删除或能力不符）。修改后页面会提示「有未保存的更改」，点击保存即刻生效。

全局只能选择全局服务商下的模型，个人服务商的模型不能设为全站默认。

::: warning 更换向量模型
不同向量模型生成的索引互不兼容。更换向量模型时，界面会提示并提供「保存并重建索引」。如果选择了「仅保存」，请稍后在知识点页面手动重建。
:::

## 我的 AI 模型（个人）

普通用户可以：

- 选择自己的**默认文本模型**和**默认识图模型**：可选任何全局模型或自己的模型；选「跟随全局默认」则沿用管理员的设置。
- 接入**自己的服务商**，使用自己的 API Key，费用计入自己的账户。

模型选择顺序：**调用时指定的模型 → 个人默认 → 全局默认**。个人默认的模型被删除或其服务商被停用时，自动回落到全局默认。

个人设置作用于本人发起的 AI 对话（聊天窗口的模型列表会分组显示「我的模型」「全局模型」，默认选中个人默认模型）、文档 / 图片导入抽取、知识点匹配。**向量模型始终使用全局配置**，因为向量索引全站共用。

管理员可以在「全局 AI 模型」页底部看到所有用户的个人服务商（不含 API Key），必要时可以删除。删除用户时，其个人服务商一并删除。

## 安全

- API Key 使用由 `SECRET_KEY` 派生的密钥**加密存储**，任何接口都不会返回 Key 本身，只返回「是否已设置」。
- 个人服务商的 Key 只用于其主人的请求，其他用户（包括管理员）既看不到，也无法调用。
- 如果更换了 `SECRET_KEY`，已保存的 Key 将无法解密，需要在界面中重新填写。
