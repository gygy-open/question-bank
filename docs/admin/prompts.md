# Prompt 模板

Prompt 模板用于保存常用的提示词，便于在对话等场景中复用。

## 模板字段

| 字段 | 说明 |
|------|------|
| 标题 | 模板名称 |
| 内容 | 提示词正文 |
| 归属 | 按用户隔离（各自管理自己的模板） |

## 操作

- 新建 / 编辑 / 删除模板
- 在 [AI 对话](/features/chat) 等流程中调用

## 与系统 Prompt 的区别

- **Prompt 模板**：用户级、可复用的提示词片段。
- **科目提示词**（题目抽取 `AI_EXTRACT_PROMPT` / 解答 `AI_SOLVE_PROMPT`）：控制抽取 / 解答行为，**按科目**配置。默认模板内置于代码，未定制的科目自动回退到默认；可在设置页按科目覆盖，或“重置为默认”删除覆盖。
- **对话工具策略**：由系统内置、随代码演进，不对外暴露编辑。
