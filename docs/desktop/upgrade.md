# 升级与卸载

## 升级到新版本

1. 从 [GitHub Releases](https://github.com/gygy-open/question-bank/releases) 下载最新安装包。
2. 右键托盘图标 → 「退出」，关闭当前应用。
3. 运行新安装包，**覆盖安装**即可。

::: tip 数据会保留
升级采用覆盖安装，程序文件被替换，但你的数据目录 `%APPDATA%\QuestionBank`（SQLite 数据库、上传文件、配置）**不受影响**。为稳妥起见，升级前仍建议先[备份](/desktop/personal#备份与恢复)。
:::

::: info 升级后首次启动
新版本首次启动时会在后台自动整理旧数据（例如把以前插入题目的图片收进「媒体库」）。整理期间题目照常可用，通常几秒到几分钟即可完成，只执行一次。
:::

安装程序在升级时会自动结束正在运行的旧版本进程，如遇「文件被占用」提示，请先手动退出应用再重试。

## 试用测试版

测试版（版本号带 `-alpha` / `-beta`，如 `1.5.0-alpha.1`）与正式版**完全隔离**，可以同时安装、同时运行：

| | 正式版 | 测试版 |
| --- | --- | --- |
| 程序名称 | QuestionBank | QuestionBank 测试版 |
| 图标颜色 | 青绿色 | 琥珀色 |
| 数据目录 | `%APPDATA%\QuestionBank` | `%APPDATA%\QuestionBank-Preview` |
| 访问地址 | `http://localhost:8000` | `http://localhost:8001` |

首次启动测试版时，如果检测到正式版的数据，会询问是否复制一份过来试用：

- 选「是」：测试版使用这份**副本**，正式版的数据不会被修改。
- 选「否」：测试版以全新状态启动。

正式版若使用 MySQL 数据库，无法自动复制，测试版会以全新状态启动。此时请不要在测试版中连接正式版正在使用的数据库。

不再需要测试版时，在「设置 → 应用」中卸载 **QuestionBank 测试版**，再删除 `%APPDATA%\QuestionBank-Preview` 即可，正式版不受影响。

::: tip 同时登录
两个版本在同一台电脑上同时打开时，登录其中一个可能会让另一个需要重新登录，属正常现象。
:::

## 卸载

1. 右键托盘图标 → 「退出」。
2. 在 Windows「设置 → 应用」或「控制面板 → 程序和功能」中找到 **QuestionBank** 并卸载。

卸载程序会：

- 结束正在运行的应用进程；
- 移除程序文件与开机自启项；
- 清理局域网共享添加的防火墙规则。

## 卸载后是否保留数据？

卸载**不会**自动删除你的数据目录 `%APPDATA%\QuestionBank`。

- 想彻底清除：手动删除该目录。
- 想保留 / 迁移：先复制该目录再删除；重新安装后放回即可恢复。

::: warning 删除不可恢复
手动删除 `%APPDATA%\QuestionBank` 会永久删除你的全部题库数据，操作前请确认已备份。
:::
