# 题干结构化

题干结构化把一道题的**题干**拆成若干「条件」和「设问」，并按学科的**元素类型**归类。拆解结果经老师审核后入库，可以用来按结构找题、看试卷的结构分布、统计命题规律。

::: tip 只看题干
拆解只使用题干（含选项），不看答案和解析。答案会给拆解带来大量噪音。
:::

## 基本概念

| 概念 | 说明 | 例子 |
| --- | --- | --- |
| 条件 | 题干给出的一件事：研究对象、已知值、关系、限制，或者会变化的量。一条只说一件事 | 「$f(x)=x^3+ax+2$」「$f(x)$ 有 3 个零点」 |
| 设问 | 要回答的一个问题；有 (1)(2) 小问时每问一条 | 「求 $a$ 的取值范围」 |
| 元素类型 | 条件 / 设问的分类，按学科组成一棵树 | 代数 › 函数 › 含参三次函数 |
| 原文位置 | 每条条件 / 设问对应题干中的哪一段文字 | 面板中高亮显示 |

元素类型和**知识点**、**标签**是三套独立的分类：

- **知识点**来自课本和课标，层级稳定；
- **标签**是知识点以外的其他分类；
- **元素类型**描述题干条件的结构，由老师维护；AI 拆解时只能从已启用的类型中选择，找不到合适类型时会给出一个描述（显示为「待归类」），留给老师整理。

## 拆解题目

1. 在题库列表中，从题目的操作菜单打开「题干结构」，或在编辑题目时点击「题干结构」，然后选择「开始拆解」。也可以勾选多道题后使用批量操作「拆解题干」。
2. 拆解在后台排队执行，与智能导入共用同一个队列。AI 服务出问题时，导入和拆解会一起暂停，并在服务恢复后一起继续。
3. 拆解完成后结果为**待审**，需要审核后才会参与检索和统计。

每次拆解都会自动体检，常见问题会标在对应条目下：

| 问题 | 含义 |
| --- | --- |
| 找不到原文 | 条目引用的文字在题干中不存在（AI 把原文改写了） |
| 重复 | 两条条件说的是同一件事 |
| 设问符号没有条件给出 | 设问用到的字母（如 $a$）没有出现在任何条件里，通常说明漏拆了一条条件 |
| 可能包含多个断言 | 一条条件里有「且」「并且」等，建议拆开（仅提醒） |
| 未覆盖的文字 | 题干中没被任何条目覆盖的文字（仅提示，「已知」「函数」这类描述词本来就不需要拆） |

体检有错误时，AI 会带着问题清单自动重拆一次。

## 审核与修改

- **审核页**（侧边栏「拆解审核」）列出当前学科所有待审拆解，有错误的排在前面。快捷键：`J` / `K` 上一条 / 下一条，`A` 采纳，`X` 驳回，`E` 编辑，`R` 重新拆解。没有错误的拆解可以批量采纳。
- **编辑**：在原文中选中一段文字，可以把它设为条件或设问；每条可以改写内容、选择类型、调整顺序、合并或拆分；设问可以勾选依赖的条件。保存后会生成一份「人工修改」的新版本，AI 的原结果仍然保留，便于对比。
- **来源**：拆解来源分为「AI 拆解」「人工修改」「外部 Agent」（经 MCP 提交）。审核页可以按来源筛选。
- **过期**：题目内容修改后，已采纳的拆解会显示「已过期」，可以一键重新拆解。系统不会自动覆盖已审核的结果。

## 材料题

材料（共享题干）单独拆解一次。拆解小题时，如果材料还没有拆过，会先拆材料；小题可以直接引用材料中的条件（显示为「来自材料」），不重复拆。

## 参数与变式

拆解时 AI 会在条件和设问下标出**参数**：老师可以改动、从而得到变式的值，例如系数、常数、长度、点的坐标。参数在原文中以虚线下划线标出，条目下显示「参数名 = 值」。

- **编辑参数**：编辑模式下，可以在原文中选中一段文字后点「设为参数」；公式里的数可以在条目下点「添加参数」并输入这个值。每个参数可以设置名称、形态、取值范围（最小、最大、整数、可选值、说明），以及是否可替换。
- **取值范围**：AI 会给出建议，老师勾选「已确认取值范围」后才生效。修改范围后，确认状态会自动取消。
- **生成变式**：在已采纳、未过期的拆解上点「生成变式」，可以为每个参数填写新值，或勾选「AI 取值」（仅限取值范围已确认的参数）。对话框会预览替换后的题干。提交后：
  1. 系统按参数在原文中的位置替换，不做全文查找替换，所以 `x^2` 里的 2 不会被误改；
  2. AI 重新解题，判断条件是否自洽、答案是否唯一、数值是否合理；选择题还要检查选项。原选项不再适用时，AI 会重写选项，界面上会提示老师核对；选项直接写在题干里的题无法重写选项，此时判为不成立；
  3. 成立时生成一道**草稿题**（照常查重），与原题以「变式」关联；不成立时显示原因，不生成题。

## 元素组与命题篮

- **元素组**：编辑模式下可以把几条条件设为一个元素组，例如「函数与零点」。组内条件都已归类时，可以「整组替换」：从其他题中挑一个条件类型组合相同的元素组替换进来，AI 改写题目并校验，生成一道变式草稿题。
- **命题篮**：在已采纳的拆解中，点条件、设问或元素组旁边的按钮可以把它加入命题篮（可以跨题，但限同一学科）。在命题篮中选择题型、写上补充说明后，由 AI 写出一道新题。系统会：
  1. 重新拆解新题，检查所选条目都在、没有多出未给出的条件；不一致时让 AI 重写一次；
  2. 解题校验；
  3. 都通过后生成草稿题，与每道来源题以「拼装」关联，新题的拆解存为待审。

## 解答结构与思维量难度

题干拆解采纳后，可以在结构面板的「解答结构」标签页拆解解答：

- 每一步写明目标、方法、结论，用到哪些条件（C1…）、设问（Q1…）和前面哪些步骤（S1…），以及作答了哪个设问；可以标记关键步，并记录这一步的常见错误（例如选择题中会导致选错的错误）。
- 体检会检查：步骤目标不为空，引用的条件和设问都存在，只引用前面的步骤，每个设问都有步骤作答。
- 一道题可以有多种解法，每种解法单独审核。
- **思维量难度**：一种解法的思维量等于各步骤方法权重之和，普通步骤记 1。方法权重在「元素类型」页的「方法」树里设置。题目的思维量难度取已采纳解法中的最小值。它和原有的 1–5 星难度并列显示，题库可以按思维量筛选和排序。
- 题干拆解被取代或题目被修改后，解答显示「需复核」。

## 元素类型管理

侧边栏「元素类型」用来维护当前学科的类型树：

- 数学学科的条件类型第一层是**代数**（式的结构）、**几何**（形的结构）、**统计**（统计量的结构），另有一个**设问**根；其他学科是一个「条件」根加一个「设问」根。另有一个**方法**根，供解答步骤归类，方法类型可以设置思维量权重。根之下的具体类型由老师添加或导入。
- 编辑类型时可以选择**对应知识点**。题干条目或解答步骤属于这个类型时，题干结构面板会向题目推荐这些知识点，一键即可添加。
- 支持新增、改名、移动、合并（引用和子类型一并迁移）、停用、删除（仅限未被引用、没有子类型的类型），以及 JSON 导入导出。
- 只有**启用**的类型会提供给 AI，并出现在筛选中。

- **待归纳**：拆解中未归类的条目，AI 会给出一个类别描述。积累到一定数量（条件或设问各至少 10 条）后，学科管理员可以在「待归纳」标签页点「开始归纳」。AI 会把含义相近的条目聚成候选类型，并给出建议的上级和相近的已有类型。老师对每个候选选择「新建为类型」「并入已有类型」或「忽略」，确认后组内条目自动归入该类型。被忽略的条目以后不再参与归纳。

维护元素类型需要该学科「编辑知识点 / 标签」的权限；发起归纳需要学科管理权限。

## 用在哪里

- **题库筛选**：按元素类型（含子类型）和结构状态（未拆解 / 待审 / 已采纳 / 已过期）筛选；列表中显示状态标记。
- **相关题**：在题干结构面板中查看已采纳的相关题，有三种找法：「类型相近」（设问类型和条件类型相近）、「共享条件」（含有相同条件，忽略排版差异）、「换了数」（参数模式相同、只是数值不同）。
- **组卷**：加题时可以按元素类型筛选；组卷侧栏显示整张卷的元素类型分布。
- **首页统计**：结构化进度、待审数量、常见元素类型、拆解来源、类型的知识点映射覆盖、有思维量难度的题数。
- **站内 AI 与 MCP**：可以读取拆解结果、按元素类型找题，并提交拆解请求。外部 AI 提交的修改只能存为待审，采纳必须由老师在站内完成。

## 开关

| 开关 | 位置 | 缺省 |
| --- | --- | --- |
| 题干结构化总开关 | 系统设置（超级管理员） | 开启。关闭后不再接受新的拆解，界面隐藏结构化入口，已有数据保留 |
| 入库后自动拆解 | 元素类型页的学科设置（学科管理员） | 关闭。开启后，新建、导入入库、审核通过的题目会自动排队拆解，会消耗 AI 额度 |

元素类型页还提供「为存量题目排队拆解」：按最低优先级排队，不会挡住老师手动发起的导入和拆解。

相关提示词都可以在学科的提示词设置中按学科覆盖：「题干拆解助手」「元素归纳助手」「变式校验助手」「命题助手」「解答拆解助手」。
