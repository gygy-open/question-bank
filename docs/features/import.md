# 智能导入

上传原始素材（文件、截图或粘贴的文本），系统在**后台识别**出结构化题目，你审核后再入库：**新建导入 → 后台识别 → 审核 → 入库**。所有导入都集中在侧边栏的「导入」页面，刷新或关闭页面不会丢失进度。

识别有两种**解析方式**：

- **AI 识别**：由 AI 自动识别题目结构，适用于格式不固定的文档与图片。
- **按标签解析**：按 `【题目】【选项】【答案】` 等标签精准解析，**不依赖 AI**、即时且可控。

默认的解析方式是**自动**：文档里有 `【题目】` 等标签时按标签解析（快，且不消耗 AI 额度），否则使用 AI 识别。

## 支持格式

| 类型 | 扩展名 | AI 识别 | 按标签解析 |
|------|--------|:---:|:---:|
| Word | `.docx` | ✅ | ✅ |
| Markdown / 纯文本 | `.md` `.txt` / 粘贴文本 | ✅ | ✅ |
| Markdown 压缩包 | `.zip`（Markdown + 引用的本地图片，整个包作为一条导入） | ✅ | ✅ |
| 图片 | `.png` `.jpg` `.jpeg` `.webp` 等，或直接粘贴截图 | ✅（视觉模型 OCR） | — |

::: tip 前置条件
**AI 识别**依赖 AI 模型：文本类使用文本模型，图片类使用**视觉模型**。请先在 [AI 供应商与模型](/admin/ai-config) 配置并激活对应模型。**按标签解析**无需任何 AI 配置。
:::

## 按标签解析

当你已有电子稿、且愿意按固定标签排版时，推荐用这种方法——**零成本、即时、100% 可控**。

### 标签语法

用 `【题目】` 分隔每一道题；一道题从 `【题目】` 开始，到下一个 `【题目】`（或文末）结束。独立题只要求 `【题目】`，材料题组还需要用结构标签声明题目材料和题组边界。

| 标签 | 字段 | 说明 |
|------|------|------|
| `【题目】` | 题干 | **必填**，同时作为每题的分隔符 |
| `【题目材料】` | 题目材料 | 题组必填；名称可选，复用同一题目材料时填写名称 |
| `【题组】` | 题组开始 | 题组必填；名称省略时引用最近声明的题目材料 |
| `【题组结束】` | 题组结束 | 可选；结束后续题目恢复为独立题 |
| `【题型】` | 题型 | 可写"单选/多选/判断/填空/解答"；省略时自动推断 |
| `【选项】` | 选项 | 块内写 `A. … B. … C. …`；或用 `【选项A】【选项B】` 逐项 |
| `【答案】` | 答案 | 选择题写字母（多选如 `AB`），判断题写 `对/错` |
| `【解析】` | 解析 | 可多行 |
| `【思路】` | 分析 | 可多行 |
| `【难度】` | 难度 | 1–5，或"简单/中等/困难" |
| `【小结】` | 小结 | 可多行 |

### 示例

```
【题目】下列关于集合的说法正确的是
【选项】A. 空集是任何集合的子集  B. 0 是空集  C. {0} 是空集  D. 以上都不对
【答案】A
【解析】空集是任何集合的子集。

【题目】判断：0 是自然数
【答案】对

【题目】1 + 1 = ____
【答案】2
```

### 材料题组与独立题混排

题组中的小题按出现顺序保存。`【题组结束】` 后的题目恢复为独立题；开始新的题组、声明新的题目材料、遇到题型大标题或到达文件末尾时，也会自动结束当前题组。

```
【题目】卷首独立题
【答案】略

【题目材料】材料一
阅读下面的文字，完成后续题目。

这里可以包含多段 Markdown 内容。

【题组】材料一
1.【题目】请概括题目材料的主要内容
【题型】解答
【答案】略

2.【题目】下列理解正确的是
【题型】单选
【选项】A. 选项一  B. 选项二
【答案】A
【题组结束】

【题目】题组后的独立题
【答案】略
```

材料名称只在当前文件内使用，系统会自动生成内部临时 ID。同一题目材料可以被多个题组复用：再次写 `【题组】材料一` 即可。题组内的 `【题目】` 只作为该题组的小题，不会在稿件中重复生成独立题。

结构标签必须独占一行。重复的题目材料名称、未知的题目材料引用、空题目材料或空题组会在审核预检时阻止导入，避免静默改变原文件结构。

### 统一答案区（可选）

有些试卷把所有题目的答案、解析统一放在文末，而不是每题后面跟 `【答案】【解析】`。这种情况下可以在正文题目之后加一个 `【答案区】` 标签（别名：`【答案表】`/`【统一答案】`/`【答案速查】`），标签之后的内容按下面两种结构解析：

```
【答案区】
| 题号 | 1 | 2 |
|:---:|:---:|:---:|
| 答案 | B | C |

1．B因为……
2．C因为……
```

- **答案**：从 `题号 | 答案` 表格里按题号取值。
- **解析**：编号段落（`1．……` `2．……`）按题号整段作为解析；段落开头若重复抄了一遍答案（如 `10．ACD对于……`），会自动去掉这段重复前缀。
- 若某道题的答案没有出现在表格里（常见于填空题、解答题，因为答案就写在解析开头，和解析连在一起不好拆分），可以在该题号下额外写 `【答案】`/`【解析】` 标签，优先级高于表格与编号段落：

  ```
  12．【答案】20/21【解析】此人患色盲的概率……
  ```

- `【答案区】` 前面允许跟着其它标题文字（如"参考答案【答案区】"），标签不要求出现在行首。

### 题型自动推断

未写 `【题型】` 时，按以下规则判断：有选项 + 单个答案字母 → 单选；有选项 + 多个字母 → 多选；无选项 + 答案为 `对/错/√/×` → 判断；无选项 + 题干含 `____` → 填空；其余 → 解答。

### 容错与提示

解析器**尽力解析、不因个别题格式问题中断**。缺答案、答案越界、题干为空、开头存在游离文本等，会在审核页对应题目上以**黄色告警**提示，你可当场修正。

## 导入流程

### 1. 新建导入

在「导入」页点击 **新建导入**，或直接把文件拖到页面上、按 `Ctrl/⌘ + V` 粘贴截图或文本。可以一次选择多个文件，每个文件生成一条导入。

导入会进入**当前学科**（在侧边栏顶部切换），识别出的题目和文档里的图片都归属这个学科。

- **解析方式**：自动（默认）/ AI 识别 / 按标签解析。
- **答案**：「使用文档中的答案」（默认），或「由 AI 补全答案和解析」。只对 AI 识别生效，选「按标签解析」时不显示；按标签解析的文档始终使用文档中的答案。
- **识别后直接入库**：跳过审核，适合格式规范、来源可靠的文档（即原来的批量导入）。

解析方式和是否直接入库会被记住，下次新建导入时直接沿用；「答案」每次都默认「使用文档中的答案」。

### 2. 后台识别

导入在后台排队识别，列表和详情页会显示当前阶段（读取文档 → 识别题目 → 匹配知识点）以及前面还有几个导入。识别期间可以离开页面或关闭浏览器，进度不会丢失；也可以随时**取消导入**。桌面版会在识别完成、失败或暂停时弹出系统通知，侧边栏的「导入」显示待审核的数量。

### 3. 审核

识别完成后导入进入「待审核」，打开即可逐题查看与编辑，字段包括：

- 题干内容、题型、选项、答案、解析、思路、难度
- AI 建议的标签（年份、来源、年级、学期、考试类型、特征等）

你可以逐题修改、删除、调整后再确认；不需要时可以**放弃本次导入**。

### 4. 入库

确认后，题目批量写入题库，并与这条导入关联，便于后续按批次筛选和管理；可同时保存为一份可编辑的稿件。

### 录入查重

进入审核页后，系统会自动把每道题与题库比对，并检查本次导入的题目之间是否互相重复（规则同 [题库管理 · 录入查重](/features/questions#录入查重)）：

- 顶部汇总本次重复、高度相似的数量；每道题旁标出“重复 / 相似 xx%”，可展开对比已有题目。
- 与题库**重复**、或与本次更早的题重复的独立题会**默认取消勾选**；高度相似的题保持勾选，只做提示。
- **保留勾选即视为确认录入**。材料题的小题不能单独取消，只做标记。
- 提交时服务端会再检查一次；审核期间别人新录入的重复题未经确认会被跳过，并在结果中说明。

## 导入状态

| 状态 | 含义 |
|------|------|
| 排队中 `pending` | 等待后台识别 |
| 识别中 `processing` | 正在读取文档、识别题目或匹配知识点 |
| 待审核 `review_ready` | 识别完成，等待你审核入库 |
| 已暂停 `paused` | AI 服务暂时不可用，见下文 |
| 已完成 `completed` | 题目已入库 |
| 失败 `failed` | 无法读取文档、没有识别到题目，或 AI 无法处理这份文档；可重新识别 |
| 已取消 `cancelled` | 已取消或已放弃；可重新识别 |

### AI 出错时

AI 调用出错时按原因处理，不会因为一次出错就丢掉整个队列：

- **临时故障**（限流、服务端错误、超时、网络中断）：自动重试几次；仍失败按「服务不可达」暂停。
- **服务或配置问题**（额度用尽、API Key 无效、模型不存在、没有配置模型）：暂停这条导入，以及排队中**使用同一服务商**的其它 AI 导入；按标签解析的导入照常进行，使用其它服务商（如个人 Key）的导入也不受影响。
- **文档本身的问题**（内容过长、输出被截断、模型输出无法解析）：只让这条导入失败，可拆分文档后重试。

暂停后的恢复方式：

| 原因 | 恢复 |
|------|------|
| 服务不可达 | 每隔 5 分钟自动重试 |
| API Key 无效 / 没有可用模型 | 修改 AI 设置后自动继续 |
| 额度用尽 | 充值后在「导入」页点 **全部继续** |

任何时候都可以手动 **继续** 单条导入，或在页面顶部点 **全部继续**；同一服务商只要有一次调用成功，因它暂停的导入会全部自动继续。

## 导入列表

- 列表按 **待审核 / 进行中 / 已暂停 / 失败 / 历史** 分组，待审核排在最前。
- **权限**：普通用户只看到自己的导入；超级管理员可在「⋯」菜单中查看所有用户或某个用户的导入，并可重置卡在「识别中」的任务。
- **疑似重复**：「识别后直接入库」的导入无人值守，不会拦截疑似重复的题，而是照常入库，并在结果中标出“疑似重复”。点开可逐题对比，勾选后一键删除不需要的新题。

## 常见问题

- **识别结果不准？** 调整 [Prompt 模板](/admin/prompts) 或更换更强的模型。
- **图片识别失败？** 确认已激活**视觉模型**，且图片清晰。
- **一直显示已暂停？** 看页面顶部的提示：额度用尽需充值后点「全部继续」；Key 或模型问题修改 AI 设置后会自动继续。
- **卡在识别中？**（服务器版）检查 [Worker 日志](/server/operations#后台任务-worker)；管理员可在「⋯」菜单中重置卡住的任务。桌面版重启后会自动把中断的导入放回队列。
