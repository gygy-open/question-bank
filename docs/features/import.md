# 智能导入

智能导入让你上传原始素材，抽取成结构化题目，遵循 **上传 → 审核 → 入库** 三步流程。支持两种**解析方法**：

- **AI 智能抽取**：由 AI 自动识别题目结构，适用于格式不固定的文档与图片。
- **标签精准解析**：按 `【题目】【选项】【答案】` 等标签精准解析，**不依赖 AI**、即时且可控。

## 支持格式

| 类型 | 扩展名 | AI 智能抽取 | 标签精准解析 |
|------|--------|:---:|:---:|
| Word | `.docx` | ✅ | ✅ |
| Markdown | `.md` / 粘贴文本 | ✅ | ✅ |
| 图片 | `.png` `.jpg` `.jpeg` `.webp` | ✅（视觉模型 OCR） | — |

::: tip 前置条件
**AI 智能抽取**依赖 AI 模型：文本类使用文本模型，图片类使用**视觉模型**。请先在 [AI 供应商与模型](/admin/ai-config) 配置并激活对应模型。**标签精准解析**无需任何 AI 配置。
:::

## 标签精准解析

当你已有电子稿、且愿意按固定标签排版时，推荐用这种方法——**零成本、即时、100% 可控**。

### 标签语法

用 `【题目】` 分隔每一道题；一道题从 `【题目】` 开始，到下一个 `【题目】`（或文末）结束。独立题只要求 `【题目】`，材料题组还需要用结构标签声明题目材料和题组边界。

| 标签 | 字段 | 说明 |
|------|------|------|
| `【题目】` | 题干 | **必填**，同时作为每题的分隔符 |
| `【题目材料】` | 题目材料 | 题组必填；名称可选，复用同一题目材料时填写名称 |
| `【题组】` | 题组开始 | 题组必填；名称省略时引用最近声明的题目材料 |
| `【题组结束】` | 题组结束 | 可选；结束后续题目恢复为独立题 |
| `【题型】` | 题型 | 可写"单选/多选/判断/填空/解答"；省略时自动推断 |
| `【选项】` | 选项 | 块内写 `A. … B. … C. …`；或用 `【选项A】【选项B】` 逐项 |
| `【答案】` | 答案 | 选择题写字母（多选如 `AB`），判断题写 `对/错` |
| `【解析】` | 解析 | 可多行 |
| `【思路】` | 分析 | 可多行 |
| `【难度】` | 难度 | 1–5，或"简单/中等/困难" |
| `【小结】` | 小结 | 可多行 |

### 示例

```
【题目】下列关于集合的说法正确的是
【选项】A. 空集是任何集合的子集  B. 0 是空集  C. {0} 是空集  D. 以上都不对
【答案】A
【解析】空集是任何集合的子集。

【题目】判断：0 是自然数
【答案】对

【题目】1 + 1 = ____
【答案】2
```

### 材料题组与独立题混排

题组中的小题按出现顺序保存。`【题组结束】` 后的题目恢复为独立题；开始新的题组、声明新的题目材料、遇到题型大标题或到达文件末尾时，也会自动结束当前题组。

```
【题目】卷首独立题
【答案】略

【题目材料】材料一
阅读下面的文字，完成后续题目。

这里可以包含多段 Markdown 内容。

【题组】材料一
1.【题目】请概括题目材料的主要内容
【题型】解答
【答案】略

2.【题目】下列理解正确的是
【题型】单选
【选项】A. 选项一  B. 选项二
【答案】A
【题组结束】

【题目】题组后的独立题
【答案】略
```

材料名称只在当前文件内使用，系统会自动生成内部临时 ID。同一题目材料可以被多个题组复用：再次写 `【题组】材料一` 即可。题组内的 `【题目】` 只作为该题组的小题，不会在稿件中重复生成独立题。

结构标签必须独占一行。重复的题目材料名称、未知的题目材料引用、空题目材料或空题组会在审核预检时阻止导入，避免静默改变原文件结构。

### 统一答案区（可选）

有些试卷把所有题目的答案、解析统一放在文末，而不是每题后面跟 `【答案】【解析】`。这种情况下可以在正文题目之后加一个 `【答案区】` 标签（别名：`【答案表】`/`【统一答案】`/`【答案速查】`），标签之后的内容按下面两种结构解析：

```
【答案区】
| 题号 | 1 | 2 |
|:---:|:---:|:---:|
| 答案 | B | C |

1．B因为……
2．C因为……
```

- **答案**：从 `题号 | 答案` 表格里按题号取值。
- **解析**：编号段落（`1．……` `2．……`）按题号整段作为解析；段落开头若重复抄了一遍答案（如 `10．ACD对于……`），会自动去掉这段重复前缀。
- 若某道题的答案没有出现在表格里（常见于填空题、解答题，因为答案就写在解析开头，和解析连在一起不好拆分），可以在该题号下额外写 `【答案】`/`【解析】` 标签，优先级高于表格与编号段落：

  ```
  12．【答案】20/21【解析】此人患色盲的概率……
  ```

- `【答案区】` 前面允许跟着其它标题文字（如"参考答案【答案区】"），标签不要求出现在行首。

### 题型自动推断

未写 `【题型】` 时，按以下规则判断：有选项 + 单个答案字母 → 单选；有选项 + 多个字母 → 多选；无选项 + 答案为 `对/错/√/×` → 判断；无选项 + 题干含 `____` → 填空；其余 → 解答。

### 容错与提示

解析器**尽力解析、不因个别题格式问题中断**。缺答案、答案越界、题干为空、开头存在游离文本等，会在审核页对应题目上以**黄色告警**提示，你可当场修正。

## 三步流程

### 1. 上传

先选择**解析方法**（AI 智能抽取 / 标签精准解析），再选择数据源上传文件或粘贴内容。

选择 **AI 智能抽取**时可进一步选处理模式：

- **抽取（extract）**：默认，从素材中抽取已有题目。
- **解答（solve）**：让 AI 对题目进行解答。

### 2. 审核

AI 抽取后，逐题展示可编辑的结果，字段包括：

- 题干内容、题型、选项、答案、解析、思路、难度
- AI 建议的标签（年份、来源、年级、学期、考试类型、特征等）

你可以逐题修改、删除、调整后再确认。

### 3. 入库

确认后，题目批量写入题库，并与本次**导入任务**关联，便于后续按批次筛选和管理。

## 导入任务状态

每次导入会生成一个导入任务，状态包括：

| 状态 | 含义 |
|------|------|
| `PENDING` | 排队中 |
| `PROCESSING` | 处理中 |
| `COMPLETED` | 已完成 |
| `FAILED` | 失败 |
| `CANCELLED` | 已取消 |

## 批次管理

- **队列状态**：查看当前排队 / 处理中 / 完成 / 失败 / 取消的统计与活动任务。
- **导入历史**：分页查看历次导入，可按状态、用户筛选。
- **权限**：超级管理员可见全部导入任务；普通用户仅见自己的。

## 常见问题

- **抽取结果不准？** 调整 [Prompt 模板](/admin/prompts) 或更换更强的模型。
- **图片识别失败？** 确认已激活**视觉模型**，且图片清晰。
- **卡在处理中？**（服务器版）检查 [Worker 日志](/server/operations#后台任务-worker)。
