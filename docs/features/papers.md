# 组卷 / 试卷管理

试卷管理支持同时维护多份试卷:在题库浏览时把题目加入某份试卷,进入独立编辑页对题目排序、增删,最终导出为试卷文件(Word / LaTeX)。

## 我的试卷

- 在侧边栏进入 **我的试卷**,可创建、重命名、复制、归档、删除多份试卷。
- 每份试卷保存在服务端(与账号绑定),换设备或清缓存都不会丢失。
- 列表支持按「最近编辑 / 创建时间 / 标题」排序,并区分「进行中」与「已归档」。

## 加入试卷

- 在 [题库管理](/features/questions) 浏览时,点击题目上的**加入试卷**按钮,弹出最近编辑的试卷,单击即加入(支持数字键 `1/2/3` 快速选择)。
- 勾选多道题后,点击**加入试卷**可批量加入同一份试卷。
- 也可在弹层中直接**新建试卷**并加入。

## 编辑试卷

进入试卷编辑页后:

- 左侧为题目列表,**拖拽题目**即可调整顺序,改动会自动保存。
- 可移除单题、查看题目详情。
- 在任意题目前可**添加大题标题**(如「一、选择题」):鼠标悬停题目卡片,点击标题图标输入即可。回车保存、`Esc` 取消,点击已有标题可再次编辑或移除。
- 右侧显示试卷信息(标题 / 学科 / 描述)与题型统计,修改后自动保存。

> 大题标题完全由你手动控制,不再按题型自动分组,可自由编排出「选择 / 填空 / 解答」等任意结构。

## 组卷导出

在编辑页点击**导出**,可选择格式与包含内容。

**导出格式:**

- **Word(DOCX)** — 默认
- **LaTeX** — LaTeX 源码(打包为 zip)

**内容选项(可勾选包含):**

| 选项 | 说明 |
|------|------|
| `include_answer` | 参考答案 |
| `include_analysis` | 解析 |
| `include_explanation` | 说明 / 解释 |
| `include_summary` | 小结 |
| `include_source` | 来源信息 |

导出文件严格按编辑页的题目顺序排版,所见即所得:

- **未添加大题标题** — 全卷从 1 连续编号。
- **添加了大题标题** — 每个大题下的题目从 1 重新编号(符合常规试卷习惯);标题前的题目归入引导部分。

## 建议流程

1. 在「我的试卷」新建一份试卷。
2. 在题库中按学科 / 知识点 / 难度筛选,逐题或批量加入该试卷。
3. 进入试卷编辑页,拖拽排序、增删题目,按需在题目前添加大题标题。
4. 选择格式与内容选项,导出并下载。
